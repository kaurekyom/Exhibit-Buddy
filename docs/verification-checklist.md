# Verification Checklist

Tick each item after the relevant stage. If you cannot verify something, write "unverified" next to it and ask Claude or a teacher.

## Stage 1: Interview engine and Open Claude button
- [ ] App opens by double-clicking index.html (no errors)
- [ ] Never asks more than 5 questions
- [ ] "Here is what I understood" summary appears before the plan is saved
- [ ] An unsafe idea (e.g. a bomb, mains electricity) is refused with no way to continue
- [ ] A risky idea (e.g. laser light show) shows an "Extra care" caution but is not refused
- [ ] An idea that is not in the library says so plainly and offers "Plan it with Claude" first
- [ ] "Digestive system" gives the Human Digestive System Model
- [ ] "Open Claude with this prompt" opens Claude in a new tab (prompt filled in, or paste with Ctrl+V)
- [ ] Every concept line in the idea library read and approved by a science teacher
- [ ] Every idea I plan to build checked against my own textbook and class level

## Stage 2: Guide renderer
- [ ] Materials list quantities match the number of parts in the templates
- [ ] Template dimensions match component cards and assembly steps
- [ ] Printed at 100% scale, the 5 cm scale bar measures exactly 5 cm
- [ ] Solid = cut, dashed = fold, glue tabs are numbered
- [ ] Non-paper materials have a reason given and a local source
- [ ] Scientific explanations ("Why it works") checked against a reliable source
- [ ] Every "Ask an adult" step is labelled
- [ ] I built the Paper Parachute and Pinhole Camera from the printed templates and noted any problems
- [ ] A pasted Claude guide was checked by the app, then read by a teacher

## Stage 3: Animated demo
- [ ] Animation step order equals written step order (tested by code; also check by eye)
- [ ] Part numbers match cards and templates
- [ ] Play, pause, next, previous, restart and speed all work
- [ ] Works on a phone and with keyboard
- [ ] Reduce-motion option works
- [ ] Final assembled shape matches the written description

## Stage 3b: 3D models, pictures and labelled figures
- [ ] Pinhole camera and parachute: every 3D step matches the written step and the part letters match the cards
- [ ] Turn the 3D model with the mouse, finger, Turn buttons and Shift + arrow keys
- [ ] The picture under each written step matches that step
- [ ] A teacher has checked every fact in the three built-in figures (animal cell, carbon atom, solar system)
- [ ] Select each part by tap, by button and by keyboard; the card text matches the part
- [ ] "Test me" asks and scores sensibly; "Pause the moving parts" works
- [ ] A figure made by Claude for a new topic was read by a teacher before use
- [ ] Printed figure page is readable

## Stage 4: Hosting and report
- [ ] Repository is public and named as instructed
- [ ] GitHub Pages enabled (main branch, root)
- [ ] Live link opens and shows the app
- [ ] Update test: change one word, commit, refresh, see the change
- [ ] Verification report lists anything unverified
- [ ] A science teacher has reviewed at least 3 generated guides
