Stage 2: Student Steps

In Stage 2 the app turns your plan into a full build guide: materials, parts, printable true-size templates, numbered steps, safety, testing, troubleshooting, viva questions and a glossary. You do every step yourself so you learn how it is made.

Time needed: about 40 minutes.

Part A: Get the new code

  1. In your Exhibit Buddy project chat, paste 00-master-prompt.md and then 02-stage-guide-renderer.md. Claude replies with the full index.html.
  2. Copy it, open your exhibit-buddy folder, open index.html in Notepad, select all (Ctrl+A), paste, save (UTF-8). Refresh the page in your browser (F5).

Part B: Test the ready-made guides

# Do this You should see
1 Start, type paper parachute, Next, Yes, this is right, Build my guide A guide with 7 steps and one template sheet with a round canopy
2 Same with pinhole camera A guide with a box net, a window and numbered glue tabs; two steps labelled Ask an adult
3 Press Print the template sheets Only the template page prints

Part C: Check the print size (most important)

  1. In the print window choose A4, scale 100% / Actual size, turn off Fit to page and headers/footers.
  2. Measure the scale bar with a ruler. It must be exactly 50 mm. If not, print again.
  3. Solid = cut. Dashed = fold. Grey numbered tab = glue to the edge with the same number.

Part D: Build one

Follow the numbered steps. Tick the testing checklist. Answer the viva questions aloud before opening the answers.

Part E: Make a guide for your own idea with Claude (two steps)

  1. Choose an idea that has no ready-made guide (for example digestive system) and press Plan it with Claude and build my guide.
  2. Step 1: press the blue Open Claude button. Press Send in Claude and answer its questions (at most 3). Claude ends with one code block.
  3. Step 2: press Copy on Claude's code block, paste it into the box in the app, press Build my guide.
  4. If a Problem list appears, copy it to Claude (same chat) and ask for a corrected code block, then paste again.
  5. Parts bigger than an A4 page (for example a 600 x 800 mm board) are shown as loose items to measure and cut yourself. The app tells you which.

Part F: Before you present

  • Ask a science teacher to read "The science" and "Viva" sections.
  • Ask an adult to check every Ask an adult step.
  • The app checks sizes, parts, steps and safety words. It does NOT check that the science or the measurements are right.

If something goes wrong

Problem Fix
Scale bar is not 50 mm Print at Actual size, not Fit to page
Paste says "typing mistake" Ask Claude to send the complete code block again
A big part shows as "loose item" Normal. It is bigger than A4, so measure and cut it by hand
